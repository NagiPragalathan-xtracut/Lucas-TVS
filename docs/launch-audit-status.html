Method

Fixes were made in the repository and checked with npm run build and the TypeScript compiler. The production build was then served locally (vite preview) and tested in a browser:

  • Hero video: network transfer and playback state at 1366 px and 640 px widths.
  • Static HTML: per-route head tags in the prerendered pages.
  • Contact form: font sizes, required flags, maxlength and the privacy link.
  • Pages: no lorem-ipsum or Insights links on /, /quality, /products and /search; valid definition lists; minimum text size; footer link heights.
  • Console: no console errors.

Not covered: Vercel-only behaviour (headers, caching, 404 status), Lighthouse scores, physical devices, and a live form submission.
